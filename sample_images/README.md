# sample_images

Place test meter photographs here for manual testing. Not committed to git
by default beyond this README — add your own images locally.

Useful test cases (see the manual testing procedure in the project README):

- a clear, well-lit, straight-on photo
- a blurry photo
- a tilted/angled photo
- a dark/underexposed photo
- a photo with glare on the display glass
- a partially cropped meter
- a photo where unrelated printed numbers (serial number, model number,
  spec plate) are visible near the display
